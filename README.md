# estudos-dados

Meu diário de aprendizado em dados: exercícios e desafios de SQL, Python, Pandas e Power BI feitos durante as formações da Alura. Meu objetivo é ingressar para área de dados.

## O que tem aqui

- `sql/consulta_escola.sql`: consultas do desafio da escola (banco com alunos, disciplinas, notas, professores e turmas):
  1. Lista todas as disciplinas
  2. Alunos com nota maior que 7 em Matemática, ordenados pela nota
  3. Quantidade de disciplinas por turma
- `sql/escola_schema.sql`: script de criação do banco da escola (`CREATE TABLE` e `INSERT`)

## Tecnologias

- SQL (SQLite)

## Em andamento

- Novas consultas (porcentagem de aprovados)
- Exercícios de Python (Pandas) e Power BI

## Como rodar as consultas

1. Abra o [SQLite Online](https://sqliteonline.com).
2. Clique em **Import** e escolha o arquivo `sql/escola_schema.sql`. Ele cria as tabelas e insere os dados.
3. Abra o arquivo `sql/consulta_escola.sql`, copie as consultas e execute.
